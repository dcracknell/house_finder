House Finder

Finds UK properties matching criteria you set, scores each one against what you actually want, adds public-record data the listing never shows you, and puts it all on an interactive map.

View on GitHub Open the live map Download the spreadsheet

What it does

Set your criteria once. It runs twice a day and keeps a running shortlist.

Searches buy and rent

Your price, bedrooms, property types and areas become real search filters, not an afterthought.

Scores every property 0–10

Against your must-haves and a plain-English description of what you want, with a one-line reason for each score.

Tells you what the listing won't

What similar homes nearby actually sold for, reported crime, flood warnings, full EPC figures and broadband speed.

Rules things out properly

Retirement homes, shared ownership, short leases, auction lots, or any phrase you ban — discarded before they reach you.

Remembers your decisions

Track viewings and offers in the spreadsheet. Your status and notes are never overwritten, and rejected properties stay gone.

Costs pennies

Cheap model by default, nothing scored twice, batched at a discount, and a hard daily spending cap.

Set it up

  1. Fork this repository. Keep it private — it records which properties you are looking at.
  2. Add an API key. Settings → Secrets and variables → Actions → New repository secret. Add ANTHROPIC_API_KEY from console.anthropic.com. Everything else is optional.
  3. Say what you want. Open a new issue, choose House search setup, and fill in the form. Submitting it saves your criteria and starts the first search.
  4. Collect your results from the links above, or from the artifacts on any run in the Actions tab.

Or run it on your own machine

git clone <your fork>
cd house_finder
python -m venv .venv && .venv\Scripts\activate
pip install -e .

house-finder ui          # set your criteria in a browser
house-finder run         # search, score, save
house-finder map-view --open

Before you rely on it

This is not property advice. Scores are a machine's opinion measured against criteria you wrote. Sold-price comparisons are rough. A flood-warning count of zero does not mean a property is outside a flood zone. Always view in person, get a survey, and use a solicitor.
It reads Rightmove's public search pages directly. Rightmove publishes no API, so this is scraping, and it is against their terms of service. At the volume here — twice a day, a few areas, with a polite delay — the realistic worst case is your IP being blocked. It will also break whenever Rightmove changes their page layout; house-finder health tells you when that has happened. You can turn it off in config/sources.yaml.
